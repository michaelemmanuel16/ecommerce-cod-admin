# M12: AI write tools

- **Goal:** The assistant can propose changes. A person sees a preview and confirms. Only then does the service run. Every write leaves an audit row with before and after.
- **Done when** (from PRD section 10, made testable):
  - Each write tool returns a preview (what changes, on which records, amounts, old and new values) and stores an `AiAction` in state `proposed`. Nothing changes until a person confirms.
  - Confirm runs the real service (ledger, stock and history side effects included) once. A double confirm runs once (idempotency key). The audit row stores `before`, `after` and `aiActionId`.
  - An AI agent key cannot confirm. A money tool never auto-confirms. The proposer who is a different actor without the permission cannot confirm.
  - A stale preview (data changed since the proposal) fails at confirm with "This changed. Review again."
  - Proposals expire after 24 hours (`expired`). A failed run sets `failed` with the reason.
  - The chat drawer shows a confirm card and the header reads "Asks you to confirm changes". Over MCP the proposal shows in the Inbox as "AI action waiting".
- **Depends on (milestones):** M2 (registry, audit, actor identity), M4 (stock and shipment services), M5 (expense and deposit services), M7 and M9 (order, reminder and comment services, inbox), M10, M11 (chat drawer, safety suite, cards)
- **PR:** one PR for this milestone. Branch `feature/m12-ai-write-tools` from `develop`, PR into `develop`. Never push to `main`. Do not push before the owner approves.
- **Owner of every task:** builder, with Opus review. No owner column.
- **Source:** `docs/prd/PRD.md` sections 5, 6, 7, 10, 11; `docs/prd/decisions.md`; the area files named in the F-IDs; design doc section 10.
- **Size key:** XS = 2 h, S = 3 to 4 h, M = 5 to 6 h, L = 7 to 8 h. Anything larger is split.
- **Working rules:** `codadmin/CLAUDE.md` applies. Run `npx prisma generate` before `tsc` (a stale client hides type errors). After each migration, apply it by hand to the test database `ecommerce_cod_test` (`cd backend && DATABASE_URL=$(grep -E '^DATABASE_URL=' .env.test | sed 's/^DATABASE_URL=//;s/"//g') npx prisma migrate deploy`); the test setup has no global migrate. Run jest with `--runInBand --forceExit`. Feature branches only; PR into `develop`.
