Build on the existing Meta integration owner choice 2026-11-11

The app already has one Facebook login (for WhatsApp), encrypted token storage, a token refresh job and a phone number picker. M8 grows this into one Meta connection. No second login. Pixel and CAPI are set per checkout form with their own token, and M8 does not change them.

  1. One Facebook login asks for WhatsApp and Ads together. After the phone number pick, a second step picks the ad accounts.
  2. One token, kept in one place. WhatsApp and the spend pull both read it. The current WhatsApp token moves there, so WhatsApp keeps working.
  3. One "Meta" card in Settings, Integrations. It shows the WhatsApp number, the ad accounts with on/off switches, last pull, and token health. Pixel and CAPI stay in each checkout form's Tracking tab, unchanged.
  4. Your store reconnects once, to add the Ads permission. Until then WhatsApp runs on the old token.

T01 also checks if Meta can give a token that does not expire (a system user token). If it can, I use it, and refresh stops being needed. This is checked, not assumed.

How I run it (same as M7, with Sonnet builders only)

  1. I write each spec and review every diff. Sonnet builder agents write all the code. No Antigravity.
  2. Up to 3 builders work at once. Each has its own worktree (m8-a, m8-b, m8-c) and its own test database (ecommerce_cod_test_a/b/c). Only lane A changes the schema.
  3. I approve each issue myself when every check passes (mode A). Checks: type check, lint, unit tests, changed-file tests, workflow validation, and a browser check with screenshots for UI work.
  4. After each approved issue I merge the lane into feature/m8-marketing, re-run the checks, update the feature doc and CHANGELOG, comment on Linear, set the issue to Done and push the branch. CI runs the full suite on a draft PR. Red CI blocks the next issue.
  5. At the end (Phase 7): one /simplify on the whole diff, then /cso and /qa on the local app. Critical and high findings get fixed. Medium and low become Backlog tickets.
  6. I stop before merge and send you the findings table and the PR link.

Defaults I will use (from the M8 plan)

  • Campaign status: Winning at or under 85% of max CPA. On track at or under max CPA. Over max CPA above it.
  • Closed cohort: orders older than 30 days.
  • Campaign tag on orders: utm_campaign and utm_content. I check what the live form sends first.
  • Daily re-pull at 05:00 Accra time. Hourly pull for today.
  • Meta card sits in Settings, Integrations. M9 moves it.
  • No fixed ₦6,400 CPA anywhere. Max CPA comes from profit before ads and yield.
