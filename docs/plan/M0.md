# M0 task plan: Correctness base

**Goal**: Make the data layer safe before any screen is rebuilt. Tenants cannot see each other's rows. The migration history builds the same schema as production. Money is `Decimal`. The public register route is gone.

**Done when** (PRD §10, made testable):
1. `cd backend && npm run test:integration -- tenantIsolation` passes. It covers orders, customers, products, deliveries, collections, GL entries, notifications, calls, order history, form submissions, SMS templates, finance models, aging buckets, MCP tools and sockets. Tenant B data never shows for tenant A.
2. CI job "migration parity": a new empty database built with `prisma migrate deploy` gives an empty `prisma migrate diff` against `schema.prisma`, and an empty diff against the production schema dump (M0-T05 and M0-T06).
3. The R15 check on production money data is written down (M0-T07) and the Decimal migration used its result. The verify script (M0-T26) prints zero difference to the cent for orders, expenses and payouts.
4. All 29 money columns in F-154 are `Decimal(19,4)` in `schema.prisma`. A test greps the money list and finds no `Float`.
5. `POST /api/auth/register` returns 404. The regression test that proved the old leak now expects 404.
6. A query on a scoped model with no tenant context throws `TenantContextMissing` (unit test).
7. The staging deploy script exits non-zero when `migrate deploy` fails (shell test).

**Depends on**: none (first milestone). Linear cleanup is done before M0 and is not a code task here.

**PR**: one PR for the whole milestone. Branch `feature/m0-correctness-base`, from `develop`, into `develop`. Never push to `main`. Do not push until the owner approves (codadmin/CLAUDE.md).

**Owner of every task**: builder, with Opus review.

Legend: Size from effort: XS = 2 h, S = 3-4 h, M = 5-6 h, L = 7-8 h. Run `cd backend && npx prisma generate` first in every new shell (memory: prisma generate first). Integration tests need the test database hand-migrated after each new migration: `cd backend && DATABASE_URL=$(grep -E '^DATABASE_URL=' .env.test | sed 's/^DATABASE_URL=//;s/"//g') npx prisma migrate deploy`. Always run Jest with `--forceExit`.
